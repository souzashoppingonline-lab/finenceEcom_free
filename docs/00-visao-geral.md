# 00 — Visão Geral

## Objetivo
Permitir que qualquer vendedor de marketplace tenha controle financeiro profissional do
seu negócio **sem depender de integração com marketplaces**. Toda informação é lançada
manualmente ou importada via Excel. O foco não é automação — é **inteligência financeira**.

## Propósito
O FinanceEcom Free **não é um ERP** nem um sistema financeiro tradicional. É uma
plataforma de inteligência financeira que transforma números em decisões. Ajuda o
empreendedor a responder:

- Estou lucrando?
- Posso comprar estoque?
- Quanto posso investir?
- Minha empresa está saudável?
- Qual loja dá mais lucro?
- Vou atingir minha meta?
- Quanto preciso vender amanhã?
- Meu caixa vai ficar negativo?

## Público
Vendedores de: Mercado Livre, Shopee, Amazon, Magalu, Shein, TikTok Shop, Loja Virtual,
WhatsApp, Instagram — e qualquer vendedor.

## Modelo de negócio
Produto **gratuito** que serve como **porta de entrada** para o ecossistema FinanceEcom:

- **FinanceEcom Free** — captação + gestão financeira básica (atual)
- **FinanceEcom Pro** — recursos avançados (futuro, pago)
- **FinanceEcom Mentoria** — educação/consultoria (futuro)

O "Free" existe para gerar **notoriedade e base de contatos** (e-mail + WhatsApp), que
alimenta o funil para Pro e Mentoria.

## Escopo desta entrega (MVP — Fase 1)
Conforme decisão do produto, o MVP entrega **somente**:

1. **Captação** de leads (nome, e-mail, WhatsApp, marketplace) com consentimento LGPD.
2. **Painel** que mostra **quantos clientes existem** e os dados de contato.
3. **Política de Privacidade**.

Os módulos financeiros (Dashboard, Vendas, Boletos, Fluxo de Caixa, DRE, Despesas,
Projeção, Metas, IA) ficam **especificados no roadmap** e serão construídos por etapas.

## Missão
Democratizar a gestão financeira para o pequeno e médio vendedor online.

## Valores
Simplicidade, transparência de dados, educação financeira, respeito à privacidade.
